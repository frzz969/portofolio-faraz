# Icons — Lucide

SVG statis diambil dari repositori Lucide, dipakai sebagai file publik dan/atau
di-inline di komponen. Tanpa paket npm, tanpa script di dalam SVG.

Semua SVG memakai `stroke="currentColor"`, jadi warna mengikuti token CSS
(`--white`, `--muted`, `--accent`). Tidak ada warna baru, glow, atau efek
brand. Ukuran dikontrol lewat CSS `width`/`height`, bukan atribut bawaan.
